# ☕ SERENATTO

Projeto desenvolvido com o objetivo de praticar e aprimorar conhecimentos em **Bootstrap**, criando uma interface moderna, responsiva e organizada para uma cafeteria.

# 🌐 Projeto online

👉 Acesse o projeto: <a href="https://projeto-serenatto-six.vercel.app/" target="_blank">Serenatto</a>

# 📖 Sobre o projeto

O **Serenatto** é um projeto inspirado em uma cafeteria, desenvolvido durante os estudos de **Bootstrap**.

A aplicação foi criada com foco na prática de componentes e recursos oferecidos pelo framework, como **Grid System, containers, responsividade, navegação, cards, carrossel, espaçamentos e classes utilitárias**.

O projeto também conta com um rodapé dinâmico, exibindo automaticamente o ano atual por meio de JavaScript.

# 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Bootstrap Icons

# 🎯 Objetivos

- Praticar a utilização do **Bootstrap**
- Trabalhar com **layouts responsivos**
- Aplicar o sistema de **Grid** do Bootstrap
- Utilizar componentes e classes utilitárias
- Desenvolver uma interface organizada e intuitiva
- Integrar **HTML, CSS e JavaScript**

# 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes tamanhos de tela, utilizando os recursos de responsividade disponibilizados pelo Bootstrap.

A interface se adapta para:

- 📱 Dispositivos móveis
- 💻 Tablets
- 🖥️ Desktops

# 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Sistema de Grid e breakpoints
- Flexbox através das classes do Bootstrap
- Containers e espaçamentos
- Componentes responsivos
- Cards
- Bootstrap Icons
- HTML semântico
- Conteúdo dinâmico com JavaScript
